# apic v0.5.0

## 新功能

- **`--pick` 分项与分组**：逗号分隔的各项都从根开始取，最后一段可写 `{...}` 分组。
  - `--pick 'code,data.username'` → `{"code":0,"username":"u"}`；`--pick 'data.{username,id},code'` 把组内的键平铺进结果。
  - `--pick 'data.list.*.{id,name}' -o table` 输出对象数组，表格只有这两列。
  - `别名=路径` 改键名，如 `--pick 'uid=data.id,code'`；没有键名段的路径（如 `*`、`0`）必须写别名。
  - 补充规则：
    - 只有一项且带别名时，输出对象 `{"uid":7}`，不直接输出值；
    - 带别名的分组不平铺，作为嵌套对象输出；
    - 分组前缀取不到或不是对象时：整个 `--pick` 只有这一个分组则退出 7，否则组内各键为 `null`；
    - `*` 之下的元素不是对象时，该元素为 `null`；元素是对象但缺某个键时，只把该键置为 `null`。
  - 只有一项且不是分组时，与以前的单路径相同：直接输出值，取不到退出 7。
  - 结果是单个对象时，`-o table` 输出 KEY/VALUE 两列。
- **分页**：站点配置 `paginate: {page, size, size_value, start, items, total}`，调用时加 `--all-pages` 取全部页并合并为一个数组。
  - `--max-pages N` 限制页数（同时开启翻页）。达到这个上限、可能还有数据时，输出已取到的部分，stderr 警告，退出 0。
  - 没给 `--max-pages` 时上限为 100 页；达到时不输出，退出 7。
  - 停止条件：某页为空；配了 `total` 时已取够；否则某页比第一页短。
  - `--pick` 与 `-o` 作用在合并后的数组上，如 `--all-pages --pick '*.{id,name}' -o table`。
  - 只支持 GET。dry-run 只打印第一页的 curl。
- **`apic use <site> --clear`**：删除保存的环境与认证；站点已从配置中删掉时，也能清掉 state 里的残留。
- **拉取定义跟随 `--env`**：给出 `--env` 时（包括写在站点名之后、快捷命令中），拉取定义用该环境的 TLS 设置（`ca_file`、`insecure`）。
- **`${exec:命令 参数...}`**：凭证值（`token`、`password`、`value`、`exec.env` 的值、`login.body` 中的字符串）可以从命令输出取值，如 `value: ${exec:pass show gitlab/token}`。
  - 不经过 shell，按空白切分，不支持引号；可与文字、`${env:}` 混写；结果不再展开。
  - 超时 30 秒，工作目录为配置目录，环境为父进程环境；输出去掉末尾换行，必须是单行。
  - 结果登记为密钥；少于 4 个字符的结果不会被遮蔽。
  - 同一进程内同一引用只执行一次。只解析所选认证。
  - dry-run 时显示为 `<exec>`，不执行；拉取定义用到的 `source.auth` 仍会执行。
  - login 的 `login.body`、exec 认证的 `exec.env` 中的 `${exec:}` 每次调用都会执行（校验缓存需要展开后的值）。
- **apic 自身的 skill**：`apic skill` 不带站点名时，生成 `<config dir>/skills/apic/SKILL.md`，介绍配置目录、加站点、简单定义格式（含示例）、站点配置、调用、输出与退出码，方便其他机器上的 agent 使用 apic。该命令不读取配置，也不含本机的站点、地址或凭证。
- **GitLab 示例**：`examples/gitlab` 改用分组写法，并加上 `paginate`。

## 兼容性变化

- **`--pick`（不兼容）**：
  - v0.4.0 的投影 `data.items.*.id,name`（`name` 跟随上一级）取消。现在逗号后的每一项都从根取，`name` 取的是根上的 `name`。请改写为 `data.items.*.{id,name}`。
  - 键名含逗号时按字面键匹配的规则取消。键名本身含 `.`、`,`、`=`、`{`、`}` 时无法用 `--pick` 访问。
  - 语法错误（空项、空段、括号不配对、分组不在最后一段、别名不合法、静态可知的重复键）改为请求前退出 2，不再发出请求。
- **保留选项名**：`all-pages`、`max-pages` 成为保留名，同名的操作参数不再生成选项，改用 `-p` 传入。
- **`--env`**：
  - 拉取定义改用 `--env` 指定的环境，而不是保存的或默认的环境。
  - `--env` 写错时，列操作和 `--help` 也会退出 1（`site "x" has no environment "y"`），并且在拉取之前就报错。
- **`${exec:}`**：
  - 凭证值中的 `${exec:...}` 以前被当作字面值发出，现在会执行命令。
  - 写在非凭证字段（`exec.command`、`apply.value`、`login.apply.value`、`token.path`、`allow_methods`、`login.path`、`username` 等）以前是字面值，现在退出 1：`auth "x": ${exec:} is only allowed in credential values`。
  - 凭证值中未闭合的 `${exec:` 退出 1：`auth "x" value: malformed ${exec:} reference`。
  - 执行失败退出 1：`auth "x" value: ${exec:} failed (exit N): <stderr 最后一行>`，消息不含命令与参数。
- **`config check`**：
  - 含 `${env:}` 或 `${exec:}` 的混写值不再报 plaintext credential。
  - 新增提示行：`runs ${exec:}`、`${exec:} is only allowed in credential values`、`malformed ${exec:} reference`。
  - exec 认证的命令以 `${exec:` 开头时显示为 `***`。
  - 退出码不变。
- **新增的 stderr 行**：
  - 分页：
    - `warning: stopped after N pages (--max-pages); more may exist`
    - `note: page N returned HTTP S; M earlier pages discarded`
    - `note: dry-run: --all-pages would request further pages`
  - `use --clear` 清理残留时，stdout 输出 `cleared`。
- **分页的退出码**：
  - 某页返回非 2xx 时，输出该页原样内容，退出码按状态码映射，3xx 为 7。
  - 以下情况退出 7，前面各页丢弃：响应不是 JSON、`items` 不是数组、`total` 不是非负整数、相邻页内容相同（`page N repeats page N-1; check paginate.page`）、达到默认上限。
  - 以下情况退出 2：站点没配 `paginate`、方法不是 GET、页码或条数不是整数、`--max-pages` 不是正整数。
- **`apic skill <site>`**：调用说明中的投影示例改为 `*.{id,name}`；站点参数改为可选。
- **配置文件**：只新增 `paginate`，v0.4.x 的配置不改也能继续使用（不含 `${exec:` 字样时）。

## 回滚到 v0.4.x

- **回退前必须把 `${exec:...}` 改回 `${env:}`**。v0.4 会把 `${exec:...}` 的命令文本当作凭证发往服务端：apikey 放在 query 时会进入访问日志和代理日志，login 会把它当密码提交，v0.4 的 `config check` 也不会告警。
- 旧版本忽略 `paginate`，`--all-pages`、`--max-pages` 会报未知选项。
- 用新写法写的 `--pick`（分组、别名）在旧版本中含义不同或报错，脚本需要一并回退。
- state 与缓存格式不变，回退无需清理。
