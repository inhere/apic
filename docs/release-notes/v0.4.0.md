# apic v0.4.0

## 新功能

- **按环境指定认证**：`envs.<env>.auth` 指定该环境使用的认证，一个站点的多个环境可以各用各的 token，不再需要写 exec 脚本。
  - 优先级：`--auth` > 环境声明 > `apic use` 保存的认证 > `default_auth`。环境声明的认证不会被保存的选择覆盖，凭证不会被带到别的环境，`allow_methods` 限制也随之生效。
  - `apic use` 显示认证来源，如 `auth: factory (env)`；保存的认证被环境声明覆盖时会提示。
  - `apic skill` 写出各环境使用的认证；`config check` 提示写错名字的 `default_auth` 和 `envs.*.auth`。
- **dry-run 容忍未设的凭证变量**：`--dry-run` 时，token、password、value、exec 的命令与环境变量、login 请求体中的 `${env:NAME}` 未设置也照样打印请求，并在 stderr 提示 `warning: dry-run: NAME is not set; a real call would fail`。认证头仍显示为 `***`，是否缺变量以警告为准。
- **`--pick` 投影**：最后一段写成 `a,b,c` 取出多个字段，如 `--pick data.items.*.id,name -o table` 只显示这两列，列序即给出的顺序；缺少的字段为 `null`。
- **简单定义的参数可写 `enum`**：`params` 中写 `enum: [opened, closed]`，调用时校验，`desc` 和补全显示。数字和布尔值按字符串比较（`1.0` 视为 `"1"`），需要原样比较时请加引号。
- **GitLab 示例**：`examples/gitlab` 提供只读 GitLab 站点（简单定义 + `PRIVATE-TOKEN` 认证 + 示例命令），复制到配置目录即可用。

## 修复

- 重新取 token 后请求仍返回 401 时，删除该认证的 token 缓存，`auth status` 不再显示 logged in。
- 配置文件带 UTF-8 BOM（Windows PowerShell 5 的 `Set-Content -Encoding utf8`、旧版记事本保存）时，`config.yaml` 中的站点被静默忽略；现在 `config.yaml`、`sites/*.yaml`、overlay、`.env`、`state.yaml`、简单定义和本地定义文件都会去掉开头的 BOM。

## 兼容性变化

- **dry-run 缺凭证变量**：以前退出 1，现在退出 0 并警告。要检查变量是否齐全，改用 `apic auth status <site> --env <env>`（缺变量退出 1）或真实调用。非凭证字段（如 `apply.header`、`login.path`）缺变量仍退出 1。
- **`--pick` 最后一段含逗号**：对象没有同名的字面键时，以前退出 7（not found），现在按投影返回。对象恰有该字面键时行为不变。
- **401 作废**：接口因权限而非 token 失效返回 401 时，刚取到的 token 也会被删除，下次调用会多执行一次 exec 或登录。需要交互（SSO/MFA）或登录有频率限制的认证请留意。
- **`apic use` 输出**：`auth:` 行多了来源后缀（`(flag)`、`(env)`、`(saved)`、`(default)`），解析该行的脚本需调整；没有认证时仍为 `auth: (none)`。
- **新增的 stderr 行**：dry-run 缺变量警告、删除 token 缓存失败警告（`warning: drop cached token: ...`）、`use` 的覆盖提示（`note: env "..." declares auth "..."; ...`）。stdout 不变。
- **`config check`**：新增两种提示行，退出码不变。
- **`apic skill`**：环境行追加 `; auth <name>`，认证一节多一句说明，调用说明多一条投影示例。
- **token 缓存文件**：加了 `envs.<env>.auth` 之后，该环境改用新认证名对应的缓存文件，旧文件残留但不再使用，可用 `apic auth logout <site> --env <env> --auth <旧名>` 删除。
- **配置文件**：只新增 `envs.<env>.auth` 和简单定义的 `enum`，v0.3.x 的配置不改也能继续使用。

## 回滚到 v0.3.x

- 旧版本忽略 `envs.<env>.auth`，所有环境改用保存的选择或 `default_auth`，可能把一个环境的 token 发往另一个环境。回退前先删掉 `envs.*.auth`，或调用时对每个环境显式加 `--auth`。
- 旧版本忽略简单定义的 `enum`，只是少了校验。
- 缓存格式不变，回退无需清缓存。
