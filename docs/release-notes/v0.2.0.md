# apic v0.2.0（草稿）

## 新功能

- **shell 补全**：支持 bash、zsh、PowerShell，可补全以下内容：
  - 站点名、操作名、参数选项和全局选项；
  - 枚举值，以及 `--env`、`--auth`、`-o` 的取值。

  补全只读缓存，不联网、不登录、不执行命令。快捷命令的补全用 `apic link ls --completion <shell>` 生成。
- **`--pick <路径>`**：从 2xx 的 JSON 响应里取值。路径支持键名、数组下标和 `*`；`*` 遇到缺少的字段填 `null`，空数组得到 `[]`。
- **`-o yaml`、`-o table`**：换一种格式输出响应，数字原文和字段顺序都保持不变。
- **`apic skill <site>`**：生成给 AI agent 用的 `SKILL.md`。来自 spec 的文本都经过净化，文件里不写 base URL 和凭证；可以用 `skillc install -S` 安装。
- **`type: exec` 认证**：由外部命令提供 token。
  - 命令按 argv 执行，不经过 shell，stdin 为空。
  - 支持超时；Unix 上超时会终止整个进程组。
  - 支持缓存与 401 后重新取 token。
  - 命令参数不出现在任何输出中。
  - Windows 上命令是 `.bat`/`.cmd` 时，拒绝含 cmd 元字符的参数。

## 兼容性变化

- **新增退出码 7**：请求已成功（2xx），但 `--pick` 或 `-o yaml|table` 处理失败。这时 stdout 为空，不要重试请求。已有退出码的含义不变。
- **全局选项 `--pick`**：站点里名为 `pick` 的参数不再生成 `--pick` 选项，请改用 `-p pick=<值>` 传入。
- **保留名 `skill`**：名为 `skill` 的站点加载时会被跳过，并给出警告，改名后才能使用；其他站点不受影响。
- **配置文件**：只新增字段，v0.1.x 的配置不改也能继续使用。

## 安全提示

用了 `exec` 认证后，`config.yaml` 和 `sites/*.yaml` 都可能让 apic 执行命令，请像对待脚本一样对待这些文件，不要导入不信任的站点文件。

## 回滚到 v0.1.x

回退前先撤掉以下配置：
- `type: exec` 认证：旧版会报未知类型；
- 值为 `yaml` 或 `table` 的 `defaults.output`，以及简单定义里的 `output:`：旧版会让调用退出 2。
